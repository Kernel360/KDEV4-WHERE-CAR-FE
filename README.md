<h1 align="center">Where Car</h1>

🚙 **차량을 관리하는 가장 스마트한 방법**

법인 차량, 렌터카, 쉐어링 차량까지 한눈에 실시간 위치 추적부터 자동 운행 일지까지,  
**차량 운영의 모든 것**을 한 플랫폼에서 해결합니다.

렌터카 업체의 효율적인 운영을 위한 차량 관리
및 관제 플랫폼을 목표로 개발하였습니다.


사용자도 쉽게 쓸 수 있고, 회사 입장에서는 차량을
더 체계적으로 관리할 수 있도록 돕습니다.
